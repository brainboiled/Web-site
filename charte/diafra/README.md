# Diafra — charte graphique

La charte complète de Diafra existe déjà et sert de **modèle** aux autres applis :

- mise en page : création Canva « Charte graphique Diafra » ;
- texte et jetons : `docs/charte/README.md` et `docs/charte/tokens.json` du dépôt Declic.

Résumé pour le site :

| Rôle | Jeton | Valeur |
|---|---|---|
| Couleur signature : symbole, nom | `or` | `#F0C454` |
| Titres des captures | `or-titre` | `#F0C860` |
| Texte sur fond sombre | `sable` | `#E8E0D0` |
| Haut des dégradés | `fond-chaud` | `#3A2C12` |
| Fond de la marque | `fond-profond` | `#16110A` |
| Accent de l'appli | `accent-collimateur` | `#FFC400` |

Police : Roboto (Bold pour le nom et les titres). Ton : tutoiement, phrases courtes, verbes d'action.
