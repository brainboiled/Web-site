Suppression de compte FlowDay

Pour supprimer vos données FlowDay :

  1. Sauvegarde Google Drive : Dans FlowDay, ouvrez Réglages > Supprimer mes données : la sauvegarde est effacée de votre Google Drive. Vous pouvez aussi supprimer les données cachées de FlowDay dans Google Drive (Paramètres > Gérer les applications), puis retirer l'accès de FlowDay sur myaccount.google.com/permissions.
  2. Agenda « FlowDay » : Si vous avez activé la synchronisation, supprimez l'agenda « FlowDay » dans Google Agenda.
  3. Données locales : Désinstallez l'application FlowDay de votre appareil.
  4. Contact : Pour toute demande de suppression, contactez flowday@brainboiled.com

Délai de traitement : 30 jours maximum.
